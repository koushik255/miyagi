# Miyagi

## Install

```sh
npm install
cd back
bun install
```

## Run

Backend:

```sh
cd back
bun run dev
```

Frontend/Electron:

```sh
npm run dev
```

Web only:

```sh
npm run dev:web
```

Tunnel mode:

```sh
cd back
bun run dev:tunnel
```

```sh
npm run dev:out
```

## Check

```sh
npm run build
npm run lint
```
